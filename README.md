# Sistema de Pedidos

Aplicação completa com backend em AdonisJS e frontend em Angular, para gerenciamento de clientes, produtos e pedidos.

## Tecnologias

- Backend: AdonisJS
- Frontend: Angular
- Banco: SQLite
- ORM: Lucid

## Estrutura

- `backend/` — API REST
- `frontend/` — interface web

## Como executar

### Backend

```bash
cd backend
npm install
node ace serve --hmr
```

### Frontend

```bash
cd frontend
npm install
npm start
```

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Ativação e inativação de produtos
- Criação de pedidos
- Atualização de status de pedidos
- Visualização de pedidos e itens

## API base

A API fica em `http://localhost:3333/api/v1`.
